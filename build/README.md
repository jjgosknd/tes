# Генератор дипломной работы

Папка содержит исходники Python-скрипта, который собирает файл
`Соловьёв_Диплом.docx` в корне репозитория.

## Запуск

```bash
python3 build/build_diploma.py
```

Никаких внешних библиотек не требуется — всё на стандартной библиотеке Python
(zipfile + xml.etree).

## Структура

| Файл | Назначение |
|------|------------|
| `build_diploma.py` | Главный сборщик — собирает все главы и упаковывает в .docx |
| `docx_build.py` | Базовая структура DOCX: Content_Types, rels, styles, footers, document |
| `helpers.py` | Хелперы для генерации параграфов, таблиц, заголовков, листингов |
| `shapes.py` | Хелперы для рисования фигур через DrawingML (rect, ellipse, arrow, line, textbox, diagram) |
| `diagrams.py` | Конкретные диаграммы для глав 2, 3 и 4 (IDEF0, DFD, ER, UML, экраны, Ганта и др.) |
| `content_intro.py` | Титульный лист, содержание, введение |
| `content_ch1.py` | Глава 1 — анализ предметной области и существующих решений |
| `content_ch2.py` | Глава 2 — проектирование (требования, архитектура, диаграммы) |
| `content_ch3.py` | Глава 3 — реализация и тестирование |
| `content_ch4.py` | Глава 4 — экономическое обоснование |
| `content_outro.py` | Заключение, список источников, приложения А и Б |

## Особенности оформления

- Шрифт Times New Roman, 14 пт, межстрочный 1,5
- Заголовки 1 уровня — по центру, заглавными
- Заголовки 2 уровня — по ширине
- Сквозная нумерация рисунков (1–18), таблиц (1–12), листингов (1–4)
- Поля по ГОСТ: верх/низ 20 мм, левое 30 мм, правое 15 мм
- Нумерация страниц начинается с 3 (введение)
- Все диаграммы — векторные DrawingML (нативные фигуры Word, редактируются)
- Листинги Courier New 12 пт, одинарный интервал
